Nikkah E-Invitation — M.A. Alkaviun Rasheeda & J. Naveeth Ahamed
==================================================================
Files
  index.html      – page structure and all invitation text (English + Tamil)
  css/style.css   – colours, layout, gate & reveal animations
  js/main.js      – gate opening, petal/sparkle canvas, countdown,
                    Add-to-Calendar (.ics), Share (WhatsApp / native share)

How to use
  1. Open index.html in any browser (works offline; Google Fonts and the
     map need internet).
  2. To share as a link, upload the whole folder to any static host
     (Netlify Drop, GitHub Pages, Vercel, Firebase Hosting) and send the URL.

Editing
  - Event date/time for the countdown & calendar: top of js/main.js
    (EVENT_START / EVENT_END).
  - Colours: :root variables at the top of css/style.css.
